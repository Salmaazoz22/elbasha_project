# El Basha — الباشا للتوريدات العمومية والمقاولات

This is the website of **El Basha for General Supplies & Contracting**, an Egyptian road and infrastructure contractor.

- **Languages:** Arabic by default at `/` (RTL); English at `/en/`.
- **Pages:** Home (services, selected projects, work video), Projects (all 27), About, Contact (WhatsApp, phone, email, contact form), and a bilingual 404 page.
- **How it's built:** plain static HTML, CSS and a little vanilla JavaScript, generated by a small Node script. There is **no framework and no npm dependency**, and no backend: the contact form posts to Formspree.
- **Hosting:** Cloudflare Pages, free plan.

## Quick start

Requires Node.js 20 or newer (`.node-version` pins 24).

```bash
npm run build           # build dist/ and run all checks (links, headings, image sizes, 25 MiB limit, no leaked markers…)
npm run preview         # serve dist/ like the host → http://127.0.0.1:4173
npm run build:drafts    # build dist-drafts/ showing every [[NEEDS_CLIENT: …]] marker for client review
npm run preview -- --drafts --port 4174
```

Set `SITE_URL` (see `.env.example`) to generate canonical and hreflang tags, social-preview URLs and `sitemap.xml`:

```bash
SITE_URL=https://example.com npm run build
```

Media tools are only needed when images or the video change:

```bash
npm run media           # source-assets/images → responsive WebP/JPEG, favicons, OG image (installs sharp temporarily)
npm run video           # source-assets/video/Final.mp4 → 52 s WebM/MP4 highlight + poster (needs ffmpeg)
```

## Where things live

```
src/data/site.json        contact details, social links, form endpoint — edit contact info here
src/data/services.json    the 10 services (ar/en)
src/data/projects.json    the 27 projects (ar/en, category, photo)
src/data/images.json      generated by `npm run media`
src/i18n/ar.json, en.json page text, SEO titles/descriptions, form messages
src/templates/            page templates (plain JS template literals)
src/assets/               CSS, JS, fonts, images, video → published with content-hashed names
src/public/               copied to the site root: _headers, _redirects, favicons, og-image.jpg
scripts/                  build.mjs · check.mjs · serve.mjs · media.mjs · video.mjs
source-assets/            original photos, logo and master video — never published
archive/                  unused originals (git-ignored, local only)
docs/                     audit, plan, QA, deployment guide, projects inventory
dist/                     build output (git-ignored) — the only folder the host publishes
```

**Missing client information** is written as `[[NEEDS_CLIENT: …]]` in the data files:
- The live build **hides** those blocks.
- The drafts build **shows** them.
- Replacing a marker with real text makes the block appear automatically.
